# LittleFS data

This folder is the safe workshop default for ESP32 LittleFS Data Upload.

Upload it with the Arduino IDE 2.x command `Upload LittleFS to Pico/ESP8266/ESP32` after selecting the `Minimal SPIFFS (1.9MB APP / 190KB SPIFFS)` partition scheme. It intentionally has no Wi-Fi password, customer profile, wallet information, or private contact details.

On first boot, CryptoClock automatically creates any optional settings files that are not included here.
