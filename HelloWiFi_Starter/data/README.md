# HelloWiFi Starter — LittleFS settings

ใช้ไฟล์ `hello-display-mode.txt` เพื่อกำหนดสีจอหลังอัปโหลด LittleFS:

- `setup` — เปิดหน้าให้แตะเลือก Black หรือ White อีกครั้ง
- `black` — ใช้พื้นหลังดำ
- `white` — ใช้พื้นหลังขาว

หลังแก้ไขไฟล์ ให้เปิด `HelloWiFi_Starter.ino` ใน Arduino IDE แล้วใช้ Command Palette:

`Upload LittleFS to Pico/ESP8266/ESP32`

คำสั่งนี้อัปโหลดเฉพาะค่าตั้งค่า ไม่ได้แฟลชโค้ด `.ino` ใหม่
